Animation

A few years ago, I was motivated to make a game with a real-time combat system (inspired by games like Nier: Automata and Devil May Cry), and I fully intended to make my own custom character animations to make sure the game felt right. I did some stepped animations as a starting point and a placeholder to build the technical implementation, but we ultimately killed the project before I found the time to transform the animation into spline. I managed to download the project and get a screencap of that stepped animation here.

Toonifying photos of friends

At some point, I thought it would be cool to practice digital linework with a Wacom pen by tracing lines from a real photo. I ended up using the base photo as a multiply layer underneath a matte fill to handle the lighting, instead of coloring in the values myself. Only found the WIP shots for one of them, the other I just found a picture of the final.
